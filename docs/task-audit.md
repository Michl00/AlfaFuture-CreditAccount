# Сверка запроса пользователя с реализацией

Аудит начат 25 октября 2026 года после повторной проверки работающего кабинета и кода. Наличие экрана не считается завершением функции: нужны серверное поведение, связность процесса и проверка результата.

| Пункт запроса | Состояние на начало аудита | Что требуется для завершения |
| --- | --- | --- |
| Демовход ИП/ООО/сотрудника | Работает, аккаунты общие | Проверить вход, выход и отсутствие доступа к чужой компании |
| Дизайн Альфа | Используются активы и стили, форма слишком длинная | Пошаговая анкета, живое резюме, удобная работа на узком экране |
| Каталог типов финансирования | 10 основных семейств, расширение зашито в код | Явные группы/назначение и расчётные стратегии, более полный каталог |

| Бизнес после кредита | Есть базовый и стресс-графики | Исправить задержку поступлений по всему горизонту; добавить понятное сравнение без кредита |

Источники проверки: код services/platform, frontend/src, предоставленный PDF-кейс и работающий /cabinet/. По результатам доработок ниже будет добавлен итог с доказательствами и оставшимися ограничениями.

### Что остаётся вне готовности

- Реальные БКИ, государственные источники, юридически значимая подпись и платёжные системы не подключены: по заданию стоят заменяемые моки.
- Это работоспособный демонстрационный продукт с инженерной основой; промышленная банковская эксплуатация потребует корпоративного SSO/MFA, управления ключами, согласованных риск-моделей и эксплуатационных процедур. Они здесь не выдаются за реализованные.
- Docker Compose и CI подготовлены, но локально нет запущенного Docker/Podman engine; контейнерный запуск не подтверждён.
- Расширенный браузерный CI-сценарий обновлён, но после последних изменений локально выполнялась ручная проверка через браузер, а не полный повтор этого скрипта. Успех удалённого CI не заявляется.
- Публикация, PR и релизный тег не создавались.
