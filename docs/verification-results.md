# Результаты локальной проверки

25 октября 2026 года. macOS arm64, Python 3.14, Node.js 26, PostgreSQL 17. Отчёт относится к текущей локальной рабочей версии.

- Сервер: **100 тестов успешно, без пропусков**, включая прежний прототип, новый конвейер, PostgreSQL-контракты, конкурирующие заявки и конкурентный захват ИИ-задания. Команда: `TEST_DATABASE_URL=postgresql+asyncpg://… .venv/bin/python -m unittest discover -s tests -q`. Время последнего запуска — 9,728 с.
- Дополнительные регрессии: независимые факторы источников, содержимое документов, задержка каждого поступления, альтернативы с авансом и разными ставками, отсутствие ложной зелёной альтернативы при закрытом бизнесе, привязка/владение оценкой, перенос чата в черновик, восстановление lease, оформление перед выплатой, личная лента, поиск до пагинации. Отдельно проверены численные галлюцинации, недопустимые ссылки и перевод сомнений ИИ сотруднику.
- Frontend: Astro check — 0 errors, 0 warnings, 0 hints; production build успешен. Ruff для новых серверных модулей и тестов — успешно.
- База: миграции применены к PostgreSQL; `alembic check` — No new upgrade operations detected. Ранее также проверен upgrade head на свежей SQLite.
- Ручная браузерная проверка текущей сборки: вход ООО и сотрудника, четыре шага заявки, 18 продуктов, расчёт и живое заключение перед согласием, восстановление той же оценки после reload, отправка и автоодобрение. Проверены ошибка/повтор оформления, ошибка/повтор выплаты, погашение и освобождение резерва; создана история шести ревизий. Проверены личная лента и обновление счётчика.
- Живой CometAPI/Qwen3-235B-A22B: заключение review-v2 сформировано в режиме llm; основания ссылаются на серверные факты. В чате модель предложила лизинг на 800 000 ₽ / 24 мес.; кнопка перенесла точные продукт, сумму, срок и цель в серверный черновик. Модель локально не скачивалась.
- Дизайн: исправлены наследуемые ограничения текста карточки (220 px) и минимальная высота (368 px); браузер подтвердил max-width:none и min-height:0. Обновлены снимки wizard, overview, ai-review и assistant. Более ранние снимки других экранов сохранены.
- Расширенный автоматический браузерный скрипт обновлён и синтаксически проверен. Его полный повтор после этих изменений локально не выполнялся; текущий сценарий выше пройден через встроенный браузер. Предыдущий автоматический E2E относился к более ранней версии. Мобильный регрессионный сценарий остаётся в CI, его результат после финальных правок здесь не заявляется.
- Docker Engine отсутствует, у установленного Podman нет машины. Compose/контейнеры подготовлены, локальная сборка и чистый контейнерный запуск не подтверждены; соответствующие шаги добавлены в CI. Удалённый CI в рамках этой работы не запускался.

Источники, договоры и выплаты используют синтетические данные. Снимки UI лежат в docs/screenshots/. Сырые ключи и ответы провайдера в отчёт не включены.
