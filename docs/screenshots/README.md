# Скриншоты интерфейса

Актуальная галерея — **current/**, съёмка **25 октября 2026 года** после восстановления темы Альфа-Бизнеса и исправления опросов/полей.

Все кадры получены из работающего Astro + FastAPI на отдельной SQLite-базе. Использованы только синтетические данные: ООО «Пример роста», 1 500 000 ₽ на 24 месяца, задача — покупка оборудования для второй кофейни. Ключи модели отключены: заключение и чат показаны в явно обозначенном режиме по правилам. Съёмка не подтверждает реальный вызов LLM или работу внешних банковских источников.

Desktop — ширина 1280 px; основные кадры 1280×720, вход и анкета сняты на всю высоту страницы. Мобильная форма — ширина 390 px, полная высота. Формат JPEG; изображения не ретушировались.

## Архив

Изображения в корне этой папки и в `design-restored/` относятся к предыдущим проходам разработки. Они сохранены для истории; основной README использует только `current/`. Старые кадры живого Qwen не описывают режим новой съёмки.

Для обновления галереи нужно переснять работающую сборку с API, дождаться окончания загрузки данных и анимаций, проверить кадры и подписи. Не заменяйте скриншоты макетами и не включайте реальные клиентские данные. Браузерный E2E-тест сохраняет диагностические изображения в корне `docs/screenshots/`; он не перезаписывает редакционную галерею `current/`.
