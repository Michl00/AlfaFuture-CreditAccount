# Восстановление дизайна рабочего кабинета

25 октября 2026. Восстановлен согласованный светлый дизайн Альфа-Бизнеса из сохранённых в проекте публичных иллюстраций справки alfabank.ru. Источники и ограничения переноса: frontend/docs/design-audit.md и /cabinet/design/.

Причина расхождения: новая оболочка ProductLayout импортировала product.css с белыми полями и горизонтальным stepper; обзор вернулся к промобаннеру и сетке каталога. Дополнительно общий промостиль global.css ограничивал внутренние div рабочих панелей до 60% ширины на mobile.

## Изменения

- Введён `frontend/src/styles/alfa-product.css`: адаптация рабочего продукта к теме `cabinet.css`, после функциональных стилей `product.css`.
- Форма слева, вертикальные этапы справа, резюме в раскрываемом блоке, действия под формой. На mobile этапы сверху и поля полной ширины.
- Сохранены все имена полей, data-* атрибуты и их серверные обработчики. Меню сохраняет профиль, выход и видимость разделов по роли; добавлены закрытие, Escape, inert и цикл Tab для мобильной версии.
- Обзор: вкладки, компания, компактная статистика, широкие строки каталога. Сохранены 18 продуктов, группы, лента событий и таблица заявок.
- Backend, правила, модели данных, миграции, зависимости и настройки развёртывания не изменялись.

## Проверки

`npm run build`: Astro/TypeScript — 0 ошибок, 0 предупреждений; 12 статических маршрутов. `git diff --check` — без ошибок.

Браузерная проверка выполнена с реальным локальным API на 8001 и отдельной SQLite-базой `/tmp/alfa-design-restore-qa.db`; рабочая база пользователя не использовалась. Вызовы платной модели отключены в тестовом процессе, заключение получено по правилам. Проверены:

- демовход ООО, серверное сохранение черновика;
- все четыре этапа, получение синтетического пакета документов, расчёт и подтверждение заявки;
- отображение созданной заявки, профиля и документов;
- доступность формы помощника (генерация ответа в этой проверке не вызывалась);
- каталог 18 продуктов и фильтр «Имущество и лизинг» (2 результата);
- вход сотрудником и отображение очереди;
- mobile 390×844: scrollWidth=390, поля полной ширины, открытие и закрытие меню;
- консоль без JavaScript errors.

Это проверка интерфейса и затронутых сценариев, а не повторная сертификация всей системы как production-ready. Выплаты и внешние интеграции не перепроверялись.

Скриншоты: `docs/screenshots/design-restored/`. Старые скриншоты сохранены. Облачное статическое Sites-демо не обновлялось: рабочий продукт теперь требует same-origin FastAPI, отсутствующего на прежнем статическом хостинге. Собранная версия доступна через существующий локальный сервер и стандартное развёртывание проекта.

## UI: опросы и поля

Исправлен сценарий помощника: один ответ больше не отправляет форму. Весь набор вопросов рендерится как опрос с независимыми radio-группами, счётчиком и одной кнопкой «Отправить ответы». До заполнения всех групп отправка недоступна. Выбранные ответы отправляются одним сообщением. При сетевой ошибке ответы и набранное сообщение сохраняются; повторная отправка доступна. Завершённые опросы и старые опросы в истории заблокированы.

В рабочей теме появились плавающие подписи: центр пустого поля → верх при фокусе/заполнении. Состояние синхронизируется и после загрузки значений из API. Длинная подпись визуально сокращается, полное название остаётся доступным. Select имеет отдельное место для стрелки. Добавлены переходы 160 мс и появление шагов/сообщений 180 мс, с отключением для prefers-reduced-motion.

Проверено через браузер с отдельной базой /tmp/alfa-ui-survey-qa.db и выключенными ключами модели:
- два выбранных ответа не создали ни одного дополнительного ChatTurn (в базе оставалась одна исходная реплика);
- нажатие «Отправить ответы» создало ровно один ChatTurn с обоими ответами;
- остановка тестового API сохранила оба выбора и доступность повтора; после запуска API повтор успешно добавил одну реплику;
- история блокирует прежние опросы;
- пустая подпись возвращается в центр после Tab, заполненная остаётся сверху; поля и select проверены при 1280 и 390 px, scrollWidth мобильной страницы = 390;
- npm run build: 0 ошибок и предупреждений.

Существующий E2E-тест обновлён регрессией двух вопросов: отсутствие запроса при выборе, единая отправка и блокировка повтора. Полный E2E-конвейер в этом проходе не запускался; сценарий проверен напрямую в браузере, синтаксис теста — node --check. Скриншот опроса: screenshots/design-restored/survey.png.
