# Astro-интерфейс Альфа Future

Основной продукт расположен на `/cabinet/`: демовход ИП/ООО/сотрудника, заявки, сценарный расчёт, документы, профиль, чат и очередь аналитика. Он подключён к `/api/v1` FastAPI и не хранит финансовые решения в localStorage.

```sh
npm ci
npm run build
npm run dev
```

Нужен Node.js >=22.23.4. Dev-сервер на `127.0.0.1:4321` проксирует `/api` к `127.0.0.1:8000`. Для полного запуска смотреть корневой README: `docker compose up --build` или `scripts/run-local.sh`. В Docker nginx обслуживает статику и API на одном origin.

`ProductLayout.astro` и `scripts/product.ts` обслуживают новый продукт. Старый `CabinetLayout.astro` сохранён для библиотеки компонентов и страниц сравнения дизайна. `/` остаётся публичным дизайн-демо при запуске Astro; в общем Docker-продукте `/` открывает кабинет.
