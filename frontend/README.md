# Astro-интерфейс Альфа Future

Основной продукт расположен на `/cabinet/`: демовход ИП/ООО/сотрудника, заявки, сценарный расчёт, документы, профиль, чат и очередь аналитика. Он подключён к `/api/v1` FastAPI и не хранит финансовые решения в localStorage.

```sh
npm ci
npm run build
npm run dev
```

Нужен Node.js >=22.23.4. Dev-сервер на `127.0.0.1:4321` проксирует `/api` к `127.0.0.1:8000`. Для полного запуска смотреть корневой README: `docker compose up --build` или `scripts/run-local.sh`. В Docker nginx обслуживает статику и API на одном origin.

`ProductLayout.astro` и `scripts/product.ts` обслуживают новый продукт. Старый `CabinetLayout.astro` сохранён для библиотеки компонентов и страниц сравнения дизайна. `/` остаётся публичным дизайн-демо при запуске Astro; в общем Docker-продукте `/` открывает кабинет.

Существующие UI-компоненты, шрифты, палитра, геометрия и адаптивные правила сохранены. Референсы и сведения об активах: docs/design-audit.md, docs/asset-sources.json, THIRD_PARTY_NOTICES. Это учебный прототип, не официальный сайт банка.

## Сохранение дизайна при дальнейших изменениях

Рабочие экраны используют общий визуальный фундамент `cabinet.css` и адаптационный слой `alfa-product.css`, который импортируется **после** `product.css` в `ProductLayout.astro`. Он восстанавливает композицию из опубликованных референсов Альфа-Бизнеса: меню 222 px, форму и этапы справа, серые поля 44 px (50 px на mobile), действия вне карточки, вкладки и широкие строки каталога.

При изменении API-сценария сохраняйте этот порядок стилей и `data-*` контракты `product.ts`. Промостили из `global.css` не должны ограничивать содержимое рабочих панелей: у `.product-card > div` сбрасывается рекламный `max-width:60%`. Новые бизнес-поля должны использовать `.credit-field` и `.form-grid`. Параметры заявки доступны в раскрываемом резюме под этапами.

Результат восстановления и проверки: `../docs/design-restoration.md`. Актуальная галерея: [скриншоты](../docs/screenshots/README.md). Предыдущие кадры сохранены в `../docs/screenshots/design-restored/`.
