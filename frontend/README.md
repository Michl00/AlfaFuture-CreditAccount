# Alfa Future UI · Astro

Самостоятельная библиотека компонентов и интерактивное демо визуального языка https://alfabank.sale, изученного 23 октября 2026 года. Это учебный прототип для хакатона, а не официальный сервис банка. Структура верхнего bento-блока, палитра, типографика, карточки и графика воспроизведены по референсу; нижние разделы адаптированы для демонстрации компонентов. Это не побайтовая копия всех страниц исходного сайта.

## Запуск

Нужен Node.js >=22.23.4, npm >=9.6.5. Версии зависимостей зафиксированы в `package-lock.json`.

```sh
cd frontend
npm ci
npm run dev
```

- `/` — демо главной страницы;
- `/components/` — интерактивный каталог всех UI-компонентов и составных блоков;
- `/cabinet/` — светлый дизайн кредитного кабинета, обзор;
- `/cabinet/new/` — четырёхшаговая анкета с примерами предложений;
- `/cabinet/applications/` — история, фильтры и поиск;
- `/cabinet/application/?id=AF-1024` — детали и статус заявки;
- `/cabinet/documents/` — документы (в демо — только метаданные);
- `/cabinet/company/` — локальный профиль компании;
- `/cabinet/bank/` — симуляция экрана сотрудника;
- `/cabinet/design/` — сверка с опубликованными иллюстрациями справки alfabank.ru.

```sh
npm run build   # Astro check + production build
npm run preview
```

Статический результат — `dist/`. Для открытия через HTTP требуется веб-сервер (не file://).

## Архитектура

```text
src/
  components/ui/       16 типизированных Astro-компонентов + общий index.ts
  components/sections/ Header, Footer, Calculator
  components/cabinet/  CreditField, CreditProgress, StatusPill, RequestCard, PageHeading
  layouts/CabinetLayout.astro светлая оболочка кредитного продукта
  styles/cabinet.css   тема кабинета (scoped через .credit-app)
  data/cabinet.ts      синтетические заявки и статусы
  styles/global.css    токены, компоненты, адаптивные правила
  layouts/Layout.astro общая оболочка, метаданные и модальное окно
  data/products.ts     синтетический каталог и примеры заявок
  scripts/ui.ts        вкладки, модальные окна, меню, уведомления, калькулятор
  scripts/cabinet.ts   локальный черновик, проверка формы, демо-заявки
  pages/               10 страниц: публичное демо, библиотека, 8 экранов кабинета
public/assets/         локальные изображения и шрифты референса
```

React не требуется. HTML рендерится при сборке; JavaScript включён только для интерактивности. Отдельного npm-пакета пока нет — библиотека импортируется из исходников. CSS глобальный: для изоляции при переносе в другой проект потребуется отдельный layout или CSS scope.

```astro
---
import { Button, Field, Badge } from '../components/ui';
---
<Badge tone="info">На рассмотрении</Badge>
<Field label="Название компании" name="company" required />
<Button variant="primary" size="lg">Продолжить</Button>
```

API компонентов — [docs/components.md](docs/components.md). План подключения backend и замечания по хакатону — [docs/integration.md](docs/integration.md). Ручные проверки — [docs/verification.md](docs/verification.md).

## Демо и данные

Кабинет хранит черновик, до 20 созданных заявок, локальные изменения статусов, профиль компании и метаданные документов в localStorage под ключом `alfa-credit-cabinet-demo-v2`. Три синтетические заявки присутствуют изначально. Клиент может ответить на уточнение, сотрудник — поменять демо-статус с комментарием. Это одна локальная симуляция, без входа, разграничения доступа, серверной истории и реальных проверок. Для восстановления начального состояния используйте кнопку на `/cabinet/design/`.

Калькулятор публичного сайта использует условные 24%; кабинет — примеры условий 24,9% и 26,9%. Это иллюстрации интерфейса, не скоринг и не предложение банка. Документы сохраняются только как название и размер; содержимое не читается и не передаётся.

Подробная сверка: [docs/design-audit.md](docs/design-audit.md). Основной образец — светлые иллюстрации кредитного интерфейса из справки alfabank.ru: форма с этапами справа и кнопками снаружи, список продуктов с вкладками и широкими карточками. Поля 44 px, радиусы 8/12 px и отступы — ориентиры реконструкции по изображениям, не извлечённые CSS банка. Актуальный закрытый кабинет не проверялся. Демо компонентов кабинета: `/cabinet/components/`.

## Docker

```sh
docker build -t alfa-future-ui ./frontend
docker run --rm -p 8080:80 alfa-future-ui
```

Образ обслуживает готовую статику на `http://localhost:8080`. Docker-конфигурация относится только к этому frontend; сервер FastAPI остаётся отдельным существующим приложением.
