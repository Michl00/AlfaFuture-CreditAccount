# Проверка новой версии кабинета

`npm run build` проверяет Astro/TypeScript и production-сборку 10 маршрутов.

Проверено в браузере 23.10.2026:
- Обзор и четырёхшаговая анкета на desktop и во фреймах шириной 390 px.
- Ошибка суммы 500 ₽ блокирует переход.
- Выбор альтернативного предложения меняет срок с 24 до 36 месяцев, условную ставку с 24,9% до 26,9%, платёж с 106 643 до 81 543 ₽ при сумме 2 млн ₽.
- После согласия локальная заявка создаётся, а её карточка показывает выбранные параметры.
- Сотрудник запрашивает уточнение с комментарием; клиент видит его и отвечает; статус возвращается на рассмотрение.
- Проверены мобильное меню и компоновка полей. Скрытая мобильная навигация исключена из фокуса через inert, открытая имеет кнопку закрытия, Escape и цикл Tab.

Проверены также фильтры/поиск, пустое состояние, сохранение профиля, восстановление начальных данных на странице сверки, Escape и возврат фокуса мобильного меню. Все десять маршрутов вернули HTTP 200; ошибок в консоли браузера не обнаружено.

Дополнительный ручной сценарий: выбор синтетического документа до 5 МБ. Документ не передаётся и не распознаётся: сохраняются только имя и размер.

Docker отсутствует на машине: сборка образа не проверена. Реальный API, вход, разграничение ролей и кредитное решение этой задачей не реализованы. Публичный сайт и библиотека сохранены.

## Структурная версия 3

Повторно проверены новый desktop 1280 px и мобильная форма 390 px, ошибка суммы 1 ₽, все четыре этапа с базовым предложением, создание локальной заявки, сброс, открытие мобильного меню, отсутствие JS errors. Новые форма/обзор и каталог компонентов построены по иллюстрациям публичной справки alfabank.ru. Сравнение находится на `/cabinet/design/`. Production-сборка содержит 11 маршрутов; детали прошлой версии выше не являются утверждением о повторном полном прогоне её сценариев после изменения оформления.
